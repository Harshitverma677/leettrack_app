LEETO MOBILE APP

Complete UI & Feature Showcase

High-fidelity interface captures of every view, modal, analytics chart, and workflow

1. Authentication & Onboarding

Sign In Screen

Clean dark-mode login interface with input validation, bcrypt-secured authentication, guest access, and quick sign-up transition.

Sign Up / Registration

Captures Display Name, Email, Password, and LeetCode handle with real-time profile verification and synchronization.

2. Main Dashboard & Leaderboard

Dashboard Top & Daily Challenge

Daily problem card with difficulty badge, live solve count, tag, and "Solve Now" deep link; Live Team Activity; Filter chips (+ Add, Solved, Streak, Accuracy); and Rank 1 gold card.

Full Teammate Leaderboard Roster

Continuous scrolling leaderboard with rank numbers, avatars, total solves, active streaks, POTD badges, accuracy, and difficulty distribution progress bars.

Live Search & Filter

Zero-latency real-time filtering as the user types teammate usernames or handles into the search box.

Dynamic Sorting by Streak

Leaderboard re-ordered by highest daily active streak on LeetCode with a single tap on the Streak filter chip.

3. Teammate Management & Modals

Add Teammate Modal

Bottom sheet modal triggered from the "+ Add" chip to add peers by their LeetCode username and sync their stats.

Remove Teammate Confirmation Dialog

Alert dialog triggered from the card's delete cross ("✕") icon to safely remove teammates with explicit user confirmation.

4. Teammate Analytics & Deep Dive

Teammate Detail: Header & Difficulty Split

Total problems solved (169), accuracy rate (68%), contest rating (1,620), and Easy, Medium, Hard breakdown cards.

90-Day Submission Heatmap & DSA Focus Areas

GitHub-style contribution heatmap and progress bars across key DSA topics (Array, String, Hash Table, Math, DP).

Recent Submissions Feed

Timeline of recent accepted submissions with relative timestamps and deep links to problem descriptions.

5. Personal Analytics & App Settings

Weekly Progress & Solves Chart

Solves by day bar chart, active days count (0/7), goal status, and daily average stats.

Live Team Activity Screen

Dedicated team challenge progress and team member activity feed.

Personal Profile ("My Profile")

Verified LeetCode badge (@vuvcVjbwmU), 133 active days heatmap, total problem count, and account sign-out.

Settings Screen

Daily problem goal selector, daily practice push notification toggles, reminder time picker, and account actions.
